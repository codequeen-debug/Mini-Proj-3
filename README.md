# Mini-Proj-3
Software Engineering Mini Project

My goal was to build a React application where you can Add, View, Update, and Delete grocery items while keeping my code organized into components as learned in class.

## The Project Structure

src/

components/

GroceryItem.jsx (Where my individual list items are currently stored)

App.jsx (The main file where the list lives)

App.css (styling and format

## Features
- Add Items: Quickly add new groceries to list.

- Update Items: Edit the name of an item if you made a mistake.

- Delete Items: Remove items from the list with a single click.
